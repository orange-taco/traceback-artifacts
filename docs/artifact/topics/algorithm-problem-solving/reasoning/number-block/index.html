AHA MOMENT

10번째 위치에 설치할 수 있는 블록 번호는 10의 약수다.

블록 n은 n × 2, n × 3… 위치에 설치됩니다. 따라서 위치 p에 올 수 있으려면 p = n × k, 즉 n이 p를 나누어야 합니다.

10 = 1 × 1010 = 2 × 510 = 5 × 2→ 가장 큰 진약수 5

정답 규칙: 위치 p의 값은 p보다 작고 10,000,000 이하인 약수 중 가장 큰 값입니다. 위치 1만 예외로 0입니다.

7

정말 덮어쓰기보다 효율적인가?

아이디어는 반복문의 개수가 아니라 실제 총 반복 횟수와 메모리까지 통과해야 해결책이 됩니다.

정방향 · 전체 도로 설치

  • 도로 끝을 R, 블록 수를 B라 두기
  • 블록 n은 약 R/n번 설치
  • 총합 R/1 + R/2 + … + R/B
  • 시간 O(R log B) · 공간 O(R)
VS

역방향 · 요청 위치만 계산

  • 구간 길이를 L, 끝 위치를 E라 두기
  • 각 위치에서 최대 √p까지 검사
  • 약수 쌍으로 큰 후보를 먼저 확인
  • 시간 O(L√E) · 결과 외 공간 O(1)

이중 for문이라고 무조건 O(n²)는 아니다

안쪽 반복문의 길이가 매번 n이 아니라 R/1, R/2, …, R/B처럼 줄어듭니다. 따라서 정방향 설치의 합은 조화급수가 되어 O(R log B)입니다. 반복문이 몇 겹인지보다 각 반복이 총 몇 번 실행되는지를 세어야 합니다.

이 풀이의 결론: 요청 구간만 역방향으로 계산하므로 시간은 O(L√E), 결과 배열은 O(L), 결과를 제외한 추가 공간은 O(1)입니다. 최악 상한이며, 큰 짝 약수를 일찍 찾으면 실제 반복은 더 빨리 끝날 수 있습니다.

구조를 먼저 설계하고 코드로 옮긴다

정답 규칙을 찾았으면 입력과 출력, 계산 단위를 차례로 코드 구조에 대응시킵니다.

결과는 리스트다

begin부터 end까지의 답을 순서대로 담은 리스트를 반환해야 합니다.

위치별 계산은 독립적인가?

위치 p의 답은 p의 약수만으로 결정됩니다. 다른 위치의 결과나 처리 순서는 필요 없습니다.

한 위치를 함수로 분리한다

위치 하나를 받아 최종 블록 번호 하나를 돌려주는 block_at(position)을 만듭니다.

순회하며 리스트에 넣는다

각 위치를 반복하면서 반환값을 answer.append(...)로 차례대로 모읍니다.

CODE UNLOCKED출력 리스트 → 독립성 확인 → 위치별 함수 → 구간 순회가 그대로 코드가 됩니다.
# Python · 교육용 풀이
from math import isqrt

MAX_BLOCK = 10_000_000


def block_at(position):
    if position == 1:
        return 0

    best = 1
    for divisor in range(2, isqrt(position) + 1):
        if position % divisor != 0:
            continue

        paired = position // divisor
        if paired <= MAX_BLOCK:
            return paired
        best = divisor

    return best


def solution(begin, end):
    answer = []
    for position in range(begin, end + 1):
        answer.append(block_at(position))
    return answer
