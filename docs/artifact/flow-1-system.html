TRACEBACK 스토어의 화면과 API는 어디에 있을까?

TRACEBACK은 상품 탐색·장바구니·결제·주문 조회를 목표로 하는 온라인 스토어입니다. 현재 개발 브랜치는 인증·계정 구현과 프런트 와이어프레임 중심입니다. 아래는 고객 요청이 지나가도록 설계한 인프라 경로입니다.

한눈에 보는 경로

  1. 고객브라우저스토어 화면·인증 요청
  2. 프런트엔드Vercel · React Router페이지 제공·API 경로 rewrite
  3. 백엔드EC2 · Django인증 구현·다른 기능 계획
  4. 데이터RDS · PostgreSQLDB 연결 검증 별도

브라우저의 페이지 요청은 Vercel에서 처리합니다. /api, /accounts, /_allauth 요청은 Vercel 설정의 DJANGO_ORIGIN을 통해 Django 쪽으로 전달하도록 정의되어 있습니다. Django가 DB를 사용합니다.

현재 확인 범위

스토어·장바구니·주문은 제품 목표이고, 현재 확인한 개발 코드는 인증·계정과 프런트 와이어프레임 중심입니다. Vercel rewrite는 코드에 정의되어 있지만 2026-10-04 관찰 기록에는 API HTTPS가 연결 거부 상태였습니다. 지금의 외부 접속은 다시 확인해야 합니다.
