이 학습 사이트는 어떻게 공개되나요?

저장소에 HTML 파일이 있어도 공개 사이트는 자동으로 생기지 않습니다. 게시 작업이 실행되고 성공해야 URL에서 읽을 수 있습니다.

① 문서가 게시 브랜치에 도착이 저장소의 PR을 main에 병합
② Pages 작업 성공pages.yml이 문서·이미지를 업로드
③ 공개 URL 확인orange-taco.github.io/traceback-artifacts/에서 목차 열기
PR을 병합했는데도 URL이 열리지 않나요?

이 저장소의 main에 문서가 반영된 뒤 pages.yml 작업이 성공해야 공개됩니다. PR 검사 성공과 Pages 게시 성공은 다릅니다. 병합 뒤 Pages 실행 결과와 실제 URL을 확인하세요. API 서버의 ECR 이미지 빌드·EC2 배포는 별도 작업입니다. 이 저장소의 Pages workflow

문서는 공개 학습 자료입니다. TRACEBACK의 실제 설정 상태는 각 문서에 표시된 확인 날짜를 기준으로 읽으세요.
