각 선택의 의미

SSH와 SSM

SSH는 사용자의 컴퓨터가 서버의 SSH 포트로 새 연결을 엽니다. SSM Session Manager는 EC2의 Agent가 AWS 서비스와 통신해 세션을 엽니다. 어느 방식을 택하느냐에 따라 필요한 인바운드 규칙과 접속 도구가 달라집니다.

IAM과 보안 그룹

IAM은 AWS API 작업의 허용 범위를, EC2 보안 그룹은 네트워크 연결의 허용 범위를 정합니다. 둘 중 하나만 맞아도 접속이 되는 것은 아닙니다.

TRACEBACK에서

개발 EC2 접속은 SSM 경로를 사용하도록 준비했습니다. 과거 관찰 상태와 실제 명령은 상세 문서에 기록되어 있으며, 접속 시 현재 AWS 상태를 다시 확인합니다.
