각 선택의 의미

CI와 CD

CI는 변경을 검사합니다. CD는 검증된 결과물을 대상 환경에 배포합니다. CI가 통과해도 네트워크와 실제 고객 요청이 정상이라는 뜻은 아닙니다.

이미지와 digest

컨테이너 이미지는 실행할 코드와 의존성을 묶습니다. digest는 특정 이미지 내용을 가리켜 개발에서 검사한 결과물을 운영에 그대로 옮기는 데 쓰입니다.
