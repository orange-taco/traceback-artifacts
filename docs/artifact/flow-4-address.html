TRACEBACK 실제 구성 · 04 / 05 · API 서버의 이름과 주소

Vercel은 개발 API 서버를 어떤 주소로 찾을까?

개발 API는 도메인 이름을 통해 EC2의 고정 공인 IP에 연결하도록 설정했습니다. 이름을 찾는 것과 HTTPS 요청에 성공하는 것은 서로 다른 단계입니다.

한눈에 보는 경로

  1. 프런트 설정DJANGO_ORIGINhttps://api.dev-traceback.com
  2. 이름Route 53 · A 레코드api.dev-traceback.com
  3. 주소Elastic IP3.34.78.140
  4. 대상개발 EC2Nginx → Django 예정

Vercel의 rewrite가 API origin을 사용합니다. DNS는 도메인의 IP를 알려주고, Elastic IP는 개발 EC2에 붙습니다. 그 다음 HTTPS/TLS와 API 앱이 준비되어야 응답이 돌아옵니다.

현재 확인 범위

2026-10-04 관찰 기록에는 도메인·A 레코드·EIP와 HTTP 80 경로가 확인됐고, TLS 443과 API 연결은 대기 중이었습니다. 현재 AWS·Vercel 콘솔 상태는 재확인이 필요합니다.

이 그림을 이해하거나 확인하려면
