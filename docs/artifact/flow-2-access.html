운영자는 개발 EC2에 어떻게 들어갈까?

운영자가 터미널에서 EC2의 셸을 여는 경로입니다. TRACEBACK의 개발 환경은 Session Manager(SSM)를 사용하도록 준비했습니다.

사람은 AWS에 세션을 요청하고, EC2의 Agent는 자신의 IAM 역할과 네트워크 경로로 AWS에 연결합니다. 셸 접속을 위해 EC2의 SSH 22번 포트를 열 필요가 없습니다.
